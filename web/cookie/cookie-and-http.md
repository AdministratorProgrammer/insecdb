# Связь cookie с HTTP-протоколом


### Управление состоянием:

Поскольку **HTTP** не хранит состояние, для отслеживания пользователей используются **cookies**.

*   **Cookie** - это небольшой фрагмент данных, который сервер отправляет клиенту в заголовке `Set-Cookie`. Браузер сохраняет его и автоматически отправляет обратно на сервер в заголовке `Cookie` с каждым последующим запросом к этому же домену.
*   **Сессия** - это механизм, использующий cookies для идентификации пользователя. Сервер присваивает клиенту уникальный идентификатор сессии (хранящийся в cookie) и хранит связанные с ним данные (например, корзину покупок) на своей стороне.
